Chapter 1The problem

A string has only 'x' and 'y'. Can it be split into groups where each group has some x first, then exactly the same number of y?

Chapter 4Balance

Every x is a promise: a y must come later. Every y pays one promise back.

balance = promises not yet paid (the blue dots). x: balance++. y: balance--. If balance goes below 0, a y had nothing to pay: stop and say false.
